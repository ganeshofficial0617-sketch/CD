# Customer Details PWA

Fields included:
- Customer name and number
- Nominee name and number
- Alternate number
- Monthly income
- Job details
- Job address
- Customer address
- Rent / Own
- Reference 1 name and number
- Reference 2 name and number

Data is stored locally on the device using browser localStorage.

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files in this folder to the repository root.
3. Open Settings → Pages.
4. Select Deploy from branch → main → /(root) → Save.
5. Open the generated Pages URL in Chrome.
6. Chrome menu → Add to Home screen / Install app.

## APK
After the GitHub Pages site is live, it can be packaged as an Android APK using a trusted PWA-to-APK wrapper/build service. This ZIP itself is the complete web/PWA source; GitHub Pages does not directly compile an APK.
